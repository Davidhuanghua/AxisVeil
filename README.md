# AxisVeil

AxisVeil 是一款基于 AirPods 头部运动追踪的 macOS 隐私工具。头部转离校准方向时自动模糊显示内容，重新看向 Mac 后恢复清晰。

## 运行条件

- macOS 14 或更高版本
- Xcode 15 或更高版本
- 支持头部运动数据的 AirPods / Beats，并已连接 Mac

## 直接运行

1. 解压项目，双击 `AxisVeil.xcodeproj`。
2. 在 Xcode 顶部选择 `AxisVeil > My Mac`。
3. 按 `Command + R`。
4. 首次启动时允许“运动与健身/头部运动”权限。
5. 戴好 AirPods，正视屏幕，然后点击菜单栏的眼睛图标，选择“以当前朝向校准”。
6. 校准中心左右各约 30°、上下各约 20° 保持完全清晰；越过范围后，偏转方向的一侧开始渐进模糊，继续偏转约 30°/20° 后达到最大强度。

菜单栏内可直接拖动“校准中心角度”“左右清晰范围（总宽）”和“上下清晰范围（总高）”。中心角度支持向左/右微调 30°，左右范围支持 30°～120°，上下范围支持 20°～80°，设置会自动保存；再次选择“以当前朝向校准”会将中心微调归零。

菜单打开时会**临时隐藏遮罩**，所以屏幕正处于模糊状态时也能看清并操作所有设置；菜单第一项显示当前版本号，方便确认运行的是哪个构建。

## 一键打包

双击项目根目录的 `打包 AxisVeil.command`。脚本会构建 Release 版本、执行本地临时签名，并在 `dist` 文件夹生成：

- `AxisVeil.app`：可直接双击运行。
- `AxisVeil-1.7.zip`：便于复制或发送。

脚本优先使用完整 Xcode；未安装完整 Xcode 时会自动改用 Command Line Tools 中的 Swift 编译器。

“模糊区域”子菜单可在两种覆盖方式间切换，选择同样会被记住：

- **半屏（跟随转头方向）**：只模糊偏转方向的那一侧，从屏幕边缘向中心扩展，最大约占 62%，另一侧保持清晰，适合边工作边看别处的场景。
- **全屏**：整块屏幕一起模糊，转开一点就整屏看不清，适合更严格的隐私需求。

“半屏遮挡方向”子菜单决定转头方向与遮挡侧的对应关系，选择同样会被记住：

- **同侧**：往左看时遮挡左边（默认）。
- **对侧**：往左看时遮挡右边，适合用余光看屏幕另一侧的场景。

项目默认使用 Xcode 的本地临时签名（Sign to Run Locally），只在本机运行不需要付费开发者账号。如果要把 `.app` 分发给其他 Mac，再在 **Signing & Capabilities** 中选择自己的开发团队并完成正式签名。

## 实现结构

```text
AirPods 姿态数据
      ↓
低通滤波 + 相对校准角度
      ↓
可调清晰范围 + 越界进度 + 双阈值防抖
      ↓
半屏方向遮罩 / 全屏覆盖 + 分层动态毛玻璃
```

- `AirPodsHeadTracker.swift`：读取 `CMHeadphoneMotionManager` 的 yaw/pitch，判断“正视/转开”，并按各轴清晰范围给出偏转主方向。
- `BlurOverlayController.swift`：创建不抢焦点、点击穿透、跨桌面空间的全屏系统毛玻璃。轻模糊、重模糊、色调三层各用不同宽度的过渡带（22%～34%）叠出连续的强度梯度，所以看不到界线；全屏模式下整屏均匀模糊。模糊色调、玻璃提示卡与文字会实时跟随系统深色/浅色模式，提示卡在半屏模式下落在被遮挡的一侧。
- `AppDelegate.swift`：菜单栏状态、校准、模糊区域切换和暂停检测。
- `HeadphoneAudioKeepAlive.swift`：循环播放不可感知的低电平信号，并在路由变化或姿态流停滞时自动重建，避免必须先播放音乐才能检测。
- `ReconnectPrompt.swift`：耳机断联后的“重新连接 / 暂停检测”浮动卡片，使用高对比度自适应字体和分层状态区域，始终不抢键盘焦点。

## 耳机断联保护

断开回调到达后有 **1 秒确认期**：期间重新收到姿态数据（例如切换音频路由造成的瞬时抖动）不会触发保护，屏幕保持原状。

耳机静默掉线时系统可能**根本不发断开回调**，只是不再上报姿态数据。这种情况同样会被捕获：连续两次唤醒（约 6 秒）仍收不到数据，就按掉线处理，进入下面的保护流程。

确认掉线后，由于已经没有朝向信息可用，屏幕会立刻整屏模糊，并浮出一张“重新连接 / 暂停检测”的玻璃卡片：

- 卡片**不抢键盘焦点**，不会打断正在进行的输入，也不会弹出会夺取焦点的系统对话框。
- 点击“重新连接”后持续检测耳机是否接入：未接入时提示确认耳机已连接并佩戴，接入后重建音频路由与姿态流，重新收到姿态数据即自动重新校准并退出保护。
- 选择“暂停检测”则停止追踪并移除遮罩，菜单栏里点“继续检测”可恢复。

## 调整灵敏度

打开 `AirPodsHeadTracker.swift`，修改 `Configuration`：

```swift
let clearYawDegrees = 30.0           // 默认左右清晰范围（每侧 30°），菜单滑杆可实时覆盖
let clearPitchDegrees = 20.0         // 默认上下清晰范围（每侧 20°）
let fullBlurYawOffsetDegrees = 30.0  // 越界后再偏转 30° 达到完全模糊
let fullBlurPitchOffsetDegrees = 20.0
let returnYawDegrees = 27.0          // 状态回正阈值，比越界阈值收窄 3°
let returnPitchDegrees = 18.0        // 上下回正阈值，比越界阈值收窄 2°
let transitionDelay = 0.18           // 防抖时间，单位：秒
```

## 隐私和限制

- Demo 不启用摄像头、不截取屏幕、不上传数据；判断完全在 Mac 本机完成。
- 应用会向当前音频输出发送约 -96 dBFS 的不可感知保活信号，用于让 AirPods 持续提供头部姿态；它不会暂停或占用其他应用的正常音频。
- 它检测的是“头部朝向”，不是眼球视线。只转动眼睛、头不动时无法识别。
- 当前校准方向视为主屏幕方向；多显示器场景中，转头看副屏也可能触发模糊。
- 半屏模式只遮挡偏转方向那一侧；如果更在意隐私，请在菜单里切到全屏。
- 耳机断开 1 秒后屏幕会整屏模糊保护，并给出“重新连接 / 暂停检测”的选择，不会一直遮挡。
- 系统登录界面、锁屏界面和部分受保护系统画面不由普通应用覆盖。
